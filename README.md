# Login

Proyecto de una interfaz de inicio de sesión desarrollada con HTML, CSS y JavaScript.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

## 📌 Descripción

Este proyecto consiste en la creación de una interfaz de inicio de sesión moderna y responsive. HTML se utiliza para estructurar el formulario, CSS para el diseño y JavaScript para añadir interactividad y funcionalidad.

## 🎯 Objetivo

Practicar la creación de formularios de inicio de sesión y mejorar el uso de HTML, CSS y JavaScript para desarrollar interfaces web interactivas y adaptables.
